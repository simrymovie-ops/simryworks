Site

トップ・プロフィール・連絡先

YouTube

動画タイトル・公開日時を取得し、日付分類に使います。

API Keyがない場合もタイトル同期はできますが、YouTube公開日時の自動取得にはAPI Keyが必要です。

Works

ドラッグして並び替え。YouTube URLを入れるとタイトルを同期できます。

カテゴリを選んでURLを貼り「追加」。動画URLなら1件、再生リストURLなら中の動画を1件ずつ追加します（再生リストはAPI Keyが必要）。登録済みの動画はスキップします。

Categories

MV / Shorts / Motion など、大分類を自由に追加できます。

Styles

MVの中の「かわいい / かっこいい / きれい」のような小分類。親カテゴリを選んで自由に追加できます。

Price

料金・納期・参考動画

GitHub

site-data.js を直接更新

保存前にYouTube動画のタイトルを確認します。API Keyが入力されている場合は公開日時も同期します。GitHubトークンとYouTube API Keyはsite-data.jsへ保存しません。

Backup

site-data.js の書き出し・読み込み
